One funny single-line excuse a developer gives when code breaks in production: "All 400 tests passed. Production just wasn't one of them."

The program writes that line to `/output/entry.txt` — the twist every developer recognises: the test suite was green because it never actually tested production.

## Run it

```sh
python3 main.py
```
